# Bellabeat Streamlit Application

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Upload this entire folder to a GitHub repository, then deploy `app.py` using Streamlit Community Cloud.

No API keys are required.

## Included
- Executive Dashboard
- Activity Analysis
- Sleep Analysis
- SQL Analysis using SQLite
- Insights & Recommendations

The app uses only the validated cleaned activity and sleep datasets from Deliverable 1.
